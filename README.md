## 안 나온 자리

- 바닥 일부와 카메라에서 충분히 관측되지 않은 영역에 검은 공백이 남았습니다.
- 카메라 이동량 자체는 충분했지만, 특정 면을 여러 위치와 각도에서 충분히 촬영하지 못해 해당 위치의 3D 포인트가 생성되지 않은 것으로 판단했습니다.
- 작은 점 사이의 틈은 Gaussian 크기(K)를 조금 키워 줄일 수 있지만, 실제로 촬영되지 않은 영역 자체를 복원해 주지는 않습니다.

## 기술 흐름

```text
영상
→ 24개 프레임
→ MapAnything
→ Point Cloud
→ Gaussian Splat (.ply)
→ SOG 압축
→ Spark + three.js
→ 브라우저 3D 뷰어
```

- **MapAnything**: 여러 사진에서 깊이와 카메라 위치를 추정하는 AI 모델
- **Point Cloud**: 공간을 수백만 개의 3D 점으로 표현한 중간 결과
- **Gaussian Splat**: 점에 크기·색·투명도를 주어 화면을 채우는 3D 표현 방식
- **SOG**: Gaussian Splat 데이터를 웹에 전달하기 좋게 압축한 파일 형식
- **Spark**: SOG/스플랫 데이터를 브라우저에서 실시간으로 그리는 웹 렌더링 라이브러리
